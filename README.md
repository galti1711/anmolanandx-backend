# ANMOLANANDX backend starter

Express API endpoints:
- GET /api/health
- POST /api/check-link with JSON body: {"url":"https://..."}

Run locally: install Node.js 18+, run `npm install`, then `npm start`.
Deploy as a Node web service. Build: `npm install`; Start: `npm start`.
Set FRONTEND_ORIGIN to https://anmolanandxvideodownloader.edgeone.dev.

This starter validates links and identifies the social platform; it does not download social videos yet. Add only official permitted integrations or user-owned/authorized downloadable sources. Do not bypass private content, logins, DRM, or platform restrictions.
